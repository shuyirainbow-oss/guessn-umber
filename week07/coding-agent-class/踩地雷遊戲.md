# 踩地雷遊戲說明

## 遊戲概念
踩地雷（Minesweeper）是一款經典單人益智遊戲。

玩家在方格地圖上打開格子，目標是找出所有沒有地雷的格子，並避免點開有地雷的格子。

每個非地雷格子會顯示周圍 8 個格子中地雷的數量，玩家可依此推理出地雷位置。

## 遊戲規則

1. 遊戲版面是 `N x M` 的格子。
2. 隨機放置 `K` 顆地雷。
3. 玩家可以選擇「打開」格子或「標記」格子為地雷。
4. 如果打開的格子是地雷，遊戲結束（輸）。
5. 如果打開的是安全格子，則顯示該格周圍 8 個格子的地雷數量。
6. 當所有非地雷格子都被打開時，玩家獲勝。

## 版面範例

假設 5x5 版面，地雷位置如下（X 代表地雷）：

```
0 1 X 2 1
0 1 1 2 X
0 0 0 1 1
0 0 0 1 X
0 0 0 1 1
```

玩家實際看到的介面會類似：

```
? ? ? ? ?
? ? ? ? ?
? ? ? ? ?
? ? ? ? ?
? ? ? ? ?
```

如果玩家打開第一列第一格，顯示 `0`，代表附近沒有地雷，可自動展開。

## 操作方式

- `O x y`：打開座標 `(x, y)`。
- `F x y`：標記座標 `(x, y)` 為地雷。
- `U x y`：取消標記座標 `(x, y)`。

## 判定邏輯

- 若格子是地雷：遊戲失敗。
- 若格子不是地雷：顯示周圍 8 個格子的地雷數量。
- 若數量為 `0`：自動展開周圍相鄰的安全格子。

## 實作概念

1. 建立 `board`：存放實際地雷與數字資訊。
2. 建立 `visible`：存放玩家已打開或標記的格子狀態。
3. 隨機放置地雷。
4. 計算每個安全格子的周圍地雷數量。
5. 玩家每次操作後，更新遊戲狀態並檢查勝利或失敗。

## 進階玩法

- 加入時間計時與排行榜。
- 提供三種難度：簡單、中等、困難。
- 支援滑鼠點擊或觸控版面。
- 加入自動展開周圍空白格子功能。
